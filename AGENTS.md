## Shared Rules

Shared rules must be maintained in `AGENTS.md` or the relevant document under `docs/` to avoid conflicting instructions across tools.

- Understand the request and inspect the relevant files before making changes.
- Preserve existing work and keep changes focused on the task.
- Follow documented conventions and existing patterns.
- Keep secrets and private data out of code, documentation, and logs.
- Verify changes using the available project checks. Report any checks that could not be run.
- Summarize the changes, verification results, and remaining limitations.
