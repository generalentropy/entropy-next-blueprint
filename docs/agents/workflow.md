# Agent Workflow

## Before Changes

- Read [AGENTS.md](../../AGENTS.md) and the documentation relevant to the task.
- Identify the expected outcome, constraints, and existing changes.
- Clarify ambiguities that materially affect the outcome.

## Implementation

- Follow existing conventions and keep changes within scope.
- Update related documentation when behavior or conventions change.

## Verification

- Review the changes and run the relevant checks.
- Report the outcome, checks performed, and unresolved issues.
